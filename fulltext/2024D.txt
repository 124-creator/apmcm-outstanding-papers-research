2024 APMCM summary sheet 
The integration of quantum computing and artificial intelligence represents a crucial 
direction in technological advancement. This paper applies quantum annealing 
optimization methods to construct three QUBO based models, targeting cloud computing 
resource demand prediction, Iris dataset classification, and deep learning 
recommendation systems, achieving effective transformation from traditional machine 
learning algorithms to quantum computing. 
For cloud computing resource demand prediction, using monthly resource demand 
data (9000-10588) from January to September, we constructed an AR(2) model and 
transformed it to QUBO through binary encoding and quantum annealing optimization, 
achieving October's demand prediction of 10598.776 with 95% confidence interval 
[10004.46, 11193.10]. 
For the Iris dataset classification problem, based on 150 samples with 4 features and 
3 classes, we implemented a two-stage SVM model (linear+RBF kernel) converted to 
QUBO via binary variable encoding and penalty terms, reaching 93.80% classification 
accuracy, a 5% improvement over traditional methods. 
For the deep learning recommendation system, utilizing MovieLens dataset 
(100,000 ratings, 1,000 users, 1,700 movies), we developed an NCF model transformed 
to QUBO through discrete embedding optimization and quantum annealing, resulting in 
74.24% MSE reduction and 49.25% RMSE improvement. 
In conclusion, this paper conducted in-depth research on quantum computing 
acceleration of artificial intelligence, designed three QUBO-based optimization models, 
and achieved effective transformation from traditional machine learning algorithms to 
quantum computing. These models can be extended to related fields such as financial 
forecasting, intelligent manufacturing, and supply chain optimization, providing valuable 
reference for practical applications of quantum computing in artificial intelligence. 
Keywords: Autoregressive Model, Support Vector Machine, Neural Collaborative 
Filtering, Quadratic Unconstrained Binary Optimization, MovieLens Dataset

Ⅰ. Problem Description 
A. Problem Background 
The unique characteristics of quantum superposition and entanglement in quantum 
computing enable it to achieve ultra - large - scale parallel computing. Its processing 
power far exceeds that of traditional computers, providing a brand - new approach to 
solving complex problems and processing large - scale data sets. 
When quantum computing is combined with artificial intelligence, this advantage 
becomes particularly prominent. The efficient parallel - processing ability of quantum 
computing can accelerate the operation of complex artificial intelligence algorithms, 
significantly shortening the training and inference time. Meanwhile, quantum algorithms 
perform excellently in solving optimization problems and are suitable for tasks such as 
parameter optimization in deep - learning networks. 
This revolutionary breakthrough is not only reflected in the improvement of 
computing speed, but more importantly, it provides new optimization ideas and solutions 
for artificial intelligence algorithms. Quantum computing can help overcome the 
bottlenecks of traditional computing when dealing with high - dimensional data and 
complex models, opening up new possibilities for the development of artificial 
intelligence. This combination will completely reshape the way we solve complex 
problems and promote artificial intelligence technology to a new level.

B. Problem Requirements 
Based on the above - mentioned background and the obtained data, it is necessary to 
establish a mathematical model to solve the following problems: 
(1) Problem of cloud computing resource demand prediction. Based on the given 
resource demand data from January to September, it is required to use the autoregressive 
(AR) model for analysis and predict the demand in October. 
(2) Machine learning classification problem. Use the classic Iris data set, transform 
the training process of the support vector machine (SVM) into a QUBO model, and 
solve it using quantum computing methods. 
(3) The combination of quantum computing and deep learning. Select a specific 
application scenario (such as image classification or recommendation system), design a 
deep - learning model, and transform its optimization problem into the QUBO form for 
solution.

B. Second Model Analysis 
The second task focuses on the classification problem in machine learning. The

classification, and how to simplify the problem scale while maintaining the classification 
effect. In addition, it is also necessary to balance the relationship between the choice of 
kernel function and the complexity of the QUBO model.

C. Third Model Analysis 
The third task focuses on the optimization problems in deep learning. For this task, 
the application scenarios and network structures can be independently selected, with a 
relatively high degree of freedom. The main difficulty lies in how to transform the 
training process of neural networks, especially continuous optimization processes such 
as back - propagation and gradient descent, into discrete optimization problems suitable 
for quantum computing. It is necessary to consider the simplification of network 
structures, the discrete representation of parameters, and how to achieve equivalent 
optimization effects under the QUBO (Quadratic Unconstrained Binary Optimization) 
framework. 
 
These three problems demonstrate a clear progression in complexity: The first task 
focuses on predicting cloud computing resource requirements through time series 
analysis, requiring transformation into a discrete QUBO form. The second task escalates 
to a classification problem using SVM on the Iris dataset, involving binarization and 
multi-class encoding challenges. The third task extends into optimization problems in 
deep learning, requiring the transformation of continuous neural network training 
processes into discrete optimization problems suitable for quantum computing.

a. Modeling Principles and Approach 
Cloud computing resource demand forecasting faces four core challenges. 
The first challenge is the time - correlation problem. It is manifested as a significant 
correlation in resource demands in adjacent periods, but this correlation gradually 
weakens as the time interval increases. This requires us to accurately quantify the impact 
of different time lags on the demand. 
The second challenge is the trend characteristics of data. It can be seen from the 
original data that the overall demand shows an obvious upward trend, increasing from 
9,000 in January to 10,588 in September. However, this growth is not linear, and there 
are significant fluctuations in the monthly growth rate. Therefore, the model needs to be 
able to capture both the long - term trend and short - term fluctuation characteristics of 
the data simultaneously. 
The third challenge comes from the strict requirements for prediction accuracy. In 
practical applications, the deviation of the predicted value will directly affect the 
efficiency of resource scheduling: if the prediction is too high, it will lead to idle and

value within its corresponding parameter range. 
 
ⅱ. Algorithm Control Parameters 
 
To balance global exploration and local refinement capabilities, the following 
parameters are set: 
⚫ Initial temperature set to 100, ensuring sufficient acceptance probability in the 
initial phase. 
⚫ Cooling rate chosen as 0.95, guaranteeing gradual temperature decrease. 
⚫ Termination temperature set to 0.1, ensuring adequate search process. 
⚫ 100 iterations at each temperature level, allowing sufficient system evolution. 
⚫ Maximum iteration count set to 1000, preventing excessive computation. 
 
ⅲ. Search Strategy Design 
 
The core of the algorithm lies in effective solution space exploration. For each current 
solution: 
1. Randomly select 1-3 binary bits for flipping to generate new candidate solutions. 
2. Verify feasibility of new solutions, ensuring parameter values remain within valid 
ranges. 
3. Calculate objective function value change ΔE. 
4. Apply Metropolis criterion for solution acceptance: 
◆ If ΔE<0, indicating improvement, accept directly 
◆ If ΔE>0, accept with probability exp(-ΔE/T), which decreases with 
temperature

(1) Analysis of Key Challenges 
 
In applying Support Vector Machine (SVM) to classify the Iris dataset, we face

(3) Detailed Model Components 
 
The input layer of our neural collaborative filtering model processes two main types 
of data: user-related and movie-related information. For user data, we handle both the 
unique user identifier (User ID) and associated user features including gender (encoded as 
a binary categorical variable), age (categorized into 7 distinct age groups), and occupation 
(represented across 21 different occupational categories). Similarly, for movie data, we 
process the unique movie identifier (Movie ID) along with movie features, specifically the 
genre information which is encoded as a multi-label variable spanning 18 different genre 
categories. 
For the embedding layer, we transform both user and movie inputs into dense vector 
representations within a shared dimensional space. The user embedding matrix P has 
dimensions of 1000×64, accommodating our user base of 1000 individuals, while the 
movie embedding matrix Q has dimensions of 1700×64, corresponding to our collection 
of 1700 movies. Both embeddings share the same dimensional space (d=64), which 
facilitates direct comparison and interaction between user and movie features in subsequent 
layers of the network.
