## 3. 样本里实际看见的闭环（按环节、按篇举例）

章程要的不是「像论文的排版」，而是一条可检查的链：题意复述 → 有理由的假设 → 针对每问的模型 → 实际求解（公式、算法、软件）→ 写得出的结果（数、表、图）→ 检验或改进 → 优缺点与参考文献，再用英文摘要把四问结果提前讲完。

### 3.1 题意理解与问题重述

**论文说的 / 观察到的**

- 6 篇都在摘要页之后用 Introduction / Restatement 按问拆题，目录把「问 1…问 n」映射到后文小节。例如 P2 目录将 Q1 分类、Q2 退化模型、Q3 单因子增强、Q4–Q5 复合模型与建议一一对应（队页 Contents，手册印刷页 184 附近）。
- P4 针对 2023B 官方要求「建立温度和风速的数学模型并给出 0.5 m / 0.1 m 截面」（手册印刷页 59–60），正文按无作物、有作物、改风速/改高度、再优化风机展开（目录 4.1–4.4）。

**我们的判断**

- 这是章程「表述规范性」最容易先被看到的部分：评阅人在摘要和目录里就能核对「每问是否都有着落」。t117 已有分问解答和验收矩阵，但还缺少一篇**面向提交的英文摘要+按问目录**把数字提前讲完。这是准备问题，不是重算问题。

### 3.2 假设：说明边界，而不是把硬约束假设掉

**论文说的**

- P2 队页 3：每条假设带理由，例如把色偏/低光/模糊在一定程度上视为可分特征，并限制前向散射假设不适用于高浑浊水体。
- P4 队页 4：不可压缩、均匀混合；忽略热辐射；忽略湍流；作物占立方体体积 50% 等——都是为了让场模型可算。
- P5 队页约「III. Basic assumption」：左臂简化为两段刚体（170 mm + 168 mm）、关节无耦合、力矩与角加速度成正比；同时把时间尺度因子的取值区间写成 [0.5, 1.5]。
- P6 队页 5：层为平面均匀各向同性、忽略粗糙度、法向入射等光学理想化，并说明为何需要银衬底。
- P3 队页 3–4：供需平衡、宏观指标平稳、数据无测量误差等。其中「所用数据全部准确、无误差或缺失」是很强的假设。
- P1（本题）写了 \(V_a\le 0.1\)、\(P\le 1800\)、\(u\le 8\)，但又给出超过 0.1 m³ 的外形（详见 t119）。

**我们的判断**

- 样本里的优秀论文普遍做**可计算的理想化**，并且多数会把假设单独成节。这与「违反题面已经写死的 0.1 m³ / 600 m³/h」不是一类事。P4 忽略湍流是理想化；P1 推荐 0.5 m 立方（0.125 m³）或 1.24×1.24×2.15 m 的三合一，是约束执行失败。准备时要学前者的写法，不要学后者的尺寸。

### 3.3 模型—求解—结果：创新体现在「把该问算出来」

**论文说的（各篇都有可核对的产出，不是只堆名词）**

- P2：灰度直方图 / JS 散度 RGB 直方图 / Laplacian 模糊判定；摘要给出附件分类计数「33 张模糊、215 张色偏、22 张低光照、130 张正常」；增强结果用 PSNR、UCIQE、UIQM 检验（摘要与 §4.3.4）。作者在优点里明确说**避免使用更复杂的 CNN/GAN**，以便可移植（队页 25）。这是「方法为问题服务」，不是堆最深网络。
- P3：用官方附件中的猫狗数量表（Table 1，2019–2023，队页 4 附近）做趋势，再接回归、Holt-Winters、VAR、静态/动态博弈；摘要按四问给出定性预测（猫数量继续增、狗增速可能放缓等），并有收益矩阵（队页 25）。
- P4：先用 Python 做衰减型能量/速度传递，网格 **40×20×20** 对应 10 m×3 m×2 m（队页 5 附近）；再用 **ANSYS Fluent** 做对照，定义重叠率 \(R\)，无作物 0.5 m 高度上温度/风速 \(R\) 达 89.84% 与 95.31%（正文转述 Fluent 区间与该指标）；第 4 问用遗传算法优化风机数量、位置、风速和温度。图 1 为网格，图 4–7、10–13 为 Fluent 纵剖面或截面。
- P5：DH 正运动学给出臂末端坐标 **(146.4, 84.5, 292.7) mm**；五次多项式步态；MATLAB 中 SQP 做能耗优化，表中三问都写「节能 33.3%、最优时间尺度 1.500」（摘要与结果表）。
- P6：TMM + Kirchhoff 定律；用 ASTM G173 AM1.5 太阳光谱；Table 1（队页 12）给出检验指标 \(\bar\varepsilon_\mathrm{solar}=0.0389<0.07\)、\(\sigma_\mathrm{atm}=0.1651<0.2\)；Q3 最优三层厚度 19.206 / 0.010 / 0.120 μm；Q4 成本 \$14.95 m⁻²。
- P1：摘要给出四问外形数字，并有效用表、因子曲线。但如 t119 所述，公开尺寸与自写约束不一致，且 1–5 m³/s、1–5 台空调的扫描超出题面风量和「一台三合一」的设定。

**我们的判断**

- 共性是：**每问至少有一个算出来的数或一张对应该问的图**，方法名称出现在「为了算这个数」的句子里。P2 主动不用 CNN，说明创造性不等于名词堆砌。
- 反例也在样本里：P5 的 33.3% 与时间尺度 1.500 正好落在作者自设区间 [0.5, 1.5] 的上界，且 4.00 J→2.67 J 等于除以 1.5。正文还把优化轨迹写成「拉长到原来的 1.5 倍时间」。**这不一定是错误**，但说明「写出 SQP」不等于已经展示了丰富的最优权衡；结果需要解释是不是约束边界上的尺度变换。我们引用此事作为「实际计算要经得起回算」的提醒，不是否定该文入选。
- t117 已经有大量可回算的数（例如主情景 Q=600、逐步电功率、CADR、t_enter）。缺的是把它们按章程结构收成「摘要—每问结果图/表—检验」的提交形态，而不是再换一套更炫的算法名词。

### 3.4 检验、改进、稳健性

**论文说的**

- P2 §5：参数扰动灵敏度（Fig. 26，队页 23），并改用非水下图片做鲁棒性讨论（队页 23–24）；同时承认偏置训练集的绿色色调问题。
- P3 §9（队页 27–28）：优点写 Holt-Winters 与博弈论适用性；缺点写平滑系数需手调、不规则波动会偏，静态博弈缺时间因素。**公开正文里的「检验」偏模型讨论，交叉验证/残差图不如 P2、P6 那样定量。**
- P4 §4.3.2 Validations：用 Fluent 对照和改风速/改高度情景比较（Fig. 18–19 等）；第 4 问在简化模型上做 GA，再用目标场图检查。
- P6 §5.1.4 与 Table 1：先给出物理上应满足的阈值，再报告计算值是否落入阈值。
- P1：污染物分布替换、加湿功率扰动；但题面硬约束在结果层执行不完整。
- P5：自称 MATLAB 与 Python 双平台相互验证（正文约队页中后部）；优点写 DH 可用几何反算；缺点写平面运动导致肘关节角度跳跃、SQP 可能局部最优（队页 25）。

**我们的判断**

- 「检验」在样本里主要是三类：与题面/物理阈值比（P6）、与独立算法或软件比（P4 Fluent，P2 图像质量指标）、与参数扰动比（P2、P6）。t117 已有守恒、网格、分阶段流场、COP/风量敏感性，属于同一家族，应当在提交文本里**单独成节**，让评阅人不用翻代码。
- 没有一篇把「多日 FDS 全局寻优」写成获奖手续。见第 5 节。

### 3.5 英文摘要、图表、篇幅

**观察到的**

- 6 篇都以 **202x APMCM summary sheet** 为第一页，用 For Problem 1/2/… 段落各给结论（P5、P6、P2 的摘要含具体数字；P3 的摘要偏定性预测；P1 的摘要含外形数字）。
- 都有目录、符号表、分问插图/表、文末 References；若干目录标明 Appendix 在选登截止页之后（P1、P3、可能还有 P2/P4/P5/P6 的 of-N 余页）。
- 页眉常见 “Page n of N”，N 从约 39 到 72、甚至 P1 的 72、P4 的 44。手册选登往往只有约 21–33 个队页。官方已打开的规范**没有规定必须写满多少页**；不能把「越长越容易奖」说成规则。
- 图是为问题服务的：P4 的截面/Fluent 图对应「请给出分布」的题面；P6 Table 1 对应「模型是否合理」；P2 的直方图与质量指标对应分类和增强；P1 的因子曲线好看，但扫描工况与题面风量并不一致。

**我们的判断**

- 表达规范首先是：英文摘要能独立读完四问答案、图题能对上题号、约束满足情况能在结果表里看见。不是先做精美模板。2023 通知已写明模板不做强制要求。

## 4. 反例和缺点（优秀论文也有，而且不能照抄）

1. **硬约束写在公式里、结果里不执行**（P1，本题）：\(V_a\le 0.1\) 与 0.5 m 立方、Q4 约 3.3 m³ 外形并存；风量扫描 1–5 m³/s。获奖不是正确性证明。我们的体积与风量执行不应向这篇看齐。
2. **假设过强**（P3 假设 4：数据全部准确、无误差缺失）。这与章程「假设的合理性」可能冲突；该文仍可因完整的四问预测结构入选，但不意味着这种假设值得模仿。
3. **优化落在自设边界上却缺少足够讨论**（P5 的 1.500 与整齐的 33.3%）。应在自己的文中避免只报「算法名 + 漂亮百分数」。
4. **理想化限制被作者自己写下**（P4 承认相对 CFD 软件细节有限、GA 仍是试错；P6 承认标准大气/理想光谱与实际气候、制造偏差不符；P2 承认海水背景复原弱、训练样本不足）。这反而是样本里健康的写法：先理想化把题算完，再在缺点里把边界讲清楚。
5. **数据出处有时仍偏薄**：P3 对官方附件表用得清楚，但公开页对「自行补充的跨国数据」更多是指标列举，文献 [1]–[7] 也偏方法论文。P6 对 ASTM G173 的引用更干净。官方章程要求引用数据应说明来源——这正是本题「收集市场数据」最该补的。

## 5. 以前高成本 FDS 偏执，竞赛里是不是必需？

## 7. 对用户那句「一般什么样可以获奖？」的短答（有原文依据，但不是公式）

官方只承诺评这三件事：模型及假设与结果是否合理、是否有创造性、文字是否规范；论文里应能看到假设、建模、求解、改进、分析与检验（2026/2020 章程第八条（二））。英文赛还要英文论文、摘要在第一页（报名通知；2023 提交规范）。

在已读的 6 篇选登正文里，看得见的共性是：摘要按问给结论；假设单独写清；每问有可回算的数或对题的图；有一节检验或灵敏度；文末有参考文献和自我限制。创造性表现为把该问解出来（P2 甚至特意不用更重的网络）。看不见的是打分权重，也看不见「必须 FDS」或「必须接近某套外形数字」。

同题唯一选登文（P1）说明：即使一等奖、即使被手册选登，也可以在硬约束上前后不一致。所以「多看优秀论文」应学闭环和检验，不应把 P1 的尺寸当标准答案，也不应把本样本外推成获奖概率。
