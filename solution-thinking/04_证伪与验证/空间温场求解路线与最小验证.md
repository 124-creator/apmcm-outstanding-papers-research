## 1. 问题与验收分层（先写清，再谈工具）

整体守恒加上相同风量，无法识别不同外形的空间温场效果。这是第 1 问仍然缺的核心结果。已停止的低阶射流闭合不再调参、不换名复活。

本轮把“能不能算”分成四层，避免设下“必须先有本题房间实测才能建模”的循环门槛：

1. **代码/安装验证**：求解器能在本机启动，并完成官方教程里的网格与迭代。
2. **标准算例验证**：用求解器官方或独立公开基准（最好含实验对照）比较速度或温度，阈值须预登记。理想化层流算例只能证明代码能跑，**不能**当成高雷诺房间湍流已经通过。
3. **本题外推**：把已通过第 2 层的工具用于 5 m×8 m×3 m 房间和柜式出口。即使算出来，也只是模型预测，不是实测确认。过去已看过的 Annex 20 2D1 若再用，只能称作开发验证，不得谎称盲测；应另留未用测点或换一个未用于调参的工况。
4. **实测确认**：本题房间或对口柜式出口的测量。当前没有，不阻止第 1、2 层，也不能用第 3 层代替第 4 层。

本轮目标只到第 1 层，并锁定第 2 层将使用哪一个官方算例。第 3、4 层本轮不执行。

## 3. 有界方法研究与选择

研究预算按授权控制：2 次 Web 检索、1 次 X 公共检索、5 次页面读取以内。其中一次 Web 检索包含 “Grok Bot”。社交结果只作线索，选择以官方文档为准。

打开并作为依据的官方页：

- ESI/OpenCFD Windows 快速入门：https://doc.openfoam.com/2306/quickstart/ （2023-09-05 页面标注）。写明可在 Microsoft Windows 上安装预编译包 `OpenFOAM-windows-mingw.exe`，并要求硬盘**至少有 300 MB 可用空间**；还可能需要另行安装 Microsoft MPI v10.0。这里的 300 MB 是官方给出的可用空间下限，**不是**本轮实测到的安装包字节数。
- 官方验证算例“Buoyant cavity”：https://doc.openfoam.com/2212/examples/verification-validation/heat-transfer/buoyant-cavity/ 。求解器 `buoyantSimpleFoam`，对象是封闭空腔自然对流，实验为 Betts and Bokhari，维持 19.6 K 温差，网格为 `blockMesh` 结构化网格。这是湍流浮力传热验证，不是仅用于代码检查的纯层流玩具题。
- NIST FDS-SMV 官方下载页：https://pages.nist.gov/fds-smv/downloads.html 。当前页标明版本 FDS 6.11.2 / SMV 6.11.3，提供 Windows 包。
- GitHub 官方发布页 https://github.com/firemodels/fds/releases/tag/FDS-6.11.2 （发布 2026-11-17）：资产 `FDS-6.11.2_SMV-6.11.3_win.exe` **175.4 MB**，同页还有 `FDS_Verification_Guide.pdf`（8.7 MB）和 `FDS_Validation_Guide.pdf`（50.8 MB）。

X 公共检索只作为方法线索，不是安装依据。可见有人询问能否让 Grok Bot 在本机配置 OpenFOAM、以及 OpenFOAM 是否仍仅限 Linux；也有人在本机 Linux 上用 OpenFOAM 做过夜计算。这与官方 Windows 快速入门并不矛盾：ESI 文档已经提供 Windows 预编译包，但**本机尚未安装**。

**本轮选定的唯一主路线：安装官方 NIST FDS 6.11.2 Windows 包，并在安装后先跑官方验证指南中的标准算例（本轮未安装、未跑）。**

选择理由（可靠性 / Windows 部署 / 成本）：

- FDS 是成熟的低马赫数浮力驱动流求解器，数值上求质量、动量和能量的守恒形式（LES，不是把旧分区模型换名），并带官方 HVAC 与房间通风验证材料，与室内送风问题同类，但仍须先过官方算例，不能直接外推到本题柜式出口。
- 官方提供单一 Windows 安装包，字节数有发布页可查（175.4 MB）；本机 C: 剩余 148.61 GB，内存与 CPU 充足。
- 安装后的第一个计算应来自官方 Verification Guide，而不是自编本题房间。阈值预登记后再跑。

备选（不在本轮同时安装）：ESI OpenFOAM 官方 Windows 包 + 官方 `buoyantCavity`（Betts & Bokhari，`buoyantSimpleFoam`）。优点是官方页面上已经把湍流自然对流验证写进文档；缺点是官方快速入门还可能要求另装 MS-MPI，且本轮没有测到 `OpenFOAM-windows-mingw.exe` 的准确字节数，只看到“至少 300 MB 可用空间”这一条件。

不采用：在现有 Python 里从零编写湍流 CFD；把层流腔体当作高雷诺房间已经通过；复活已停止的射流闭合；为凑结果去装来源不明的包。
